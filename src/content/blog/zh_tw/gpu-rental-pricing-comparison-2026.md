## 摘要總覽

2026 年的 GPU 租用價格，會因供應商類型與硬體選擇而有很大落差。AWS、Azure、GCP 等企業級雲端服務供應商收費較高，入門級 GPU 每小時 $0.80 起，高階配置每小時超過 $30。點對點市集平台提供同樣的硬體，價格便宜 60-80%，但可用性的保障較低。

**本次分析的主要發現：**

| 供應商類型                         | A100 一般價格 | 適合對象                          |
| ---------------------------------- | ------------- | --------------------------------- |
| 企業級雲端（AWS、Azure、GCP）      | $25-35/小時   | 合規需求、保證正常運作時間、企業支援 |
| 代管型市集平台（RunPod）           | $1.39-1.89/小時 | 兼顧穩定度與成本                  |
| 點對點市集平台（Vast.ai）          | $0.84-1.49/小時 | 追求最大省幅、彈性工作負載        |

最划算的選擇取決於三個因素：正常運作時間要求、合規需求，以及工作負載的彈性。本指南提供具體的價格資料與判斷標準，幫助您找到適合自己的方案。

## 認識 GPU 租用市場

GPU 租用市場已經分化成兩大類。企業級雲端服務供應商自行營運資料中心，提供標準化硬體、有保證的可用性，以及企業級服務水準協議（SLA）。這類供應商鎖定的是需要合規認證、效能穩定可預期，以及專屬支援管道的組織。

點對點市集平台走的是另一條路。這些平台把個人 GPU 擁有者（從遊戲玩家到加密貨幣礦工都有）和需要運算資源的使用者連結起來。分散式的模式省去了資料中心的營運成本，讓租用者享有大幅節省，同時也為硬體擁有者創造收入。

兩種模式沒有絕對的優劣，正確的選擇取決於工作負載的特性。可以容忍中斷的訓練工作，適合利用市集平台的低價；需要五個九（99.999%）可用性的正式環境推論系統，則值得付出企業級的溢價。

**目前的市場態勢對租用者有利。** 2024 到 2026 年間 GPU 供應改善，讓各類供應商的價格都有所鬆動。市集平台之間的競爭，已把消費級 GPU 的租金壓到每小時 $0.50 以下。企業級供應商也以更有彈性的承諾方案與 Spot 執行個體作為回應。

## 各供應商分析

### Amazon Web Services (AWS)

Amazon Web Services 透過 EC2 執行個體提供 GPU 運算，可使用 V100、A100 以及較新的 H100 等 NVIDIA 資料中心 GPU。AWS 屬於 GPU 租用的高價位層級，優先考量的是穩定度與生態系整合，而不是成本效益。

**AWS GPU 執行個體最適合已深度使用 AWS 生態系的組織**，這些組織需要與 S3 儲存空間、SageMaker 管線及企業資安框架無縫整合。價格反映的是資料中心等級的穩定度，以及 99.99% 正常運作時間的 SLA。

**目前價格（美國東部區域，隨需計費）：**

| 執行個體     | GPU 配置          | 每小時費率 |
| ------------ | ----------------- | ---------- |
| p4d.24xlarge | 8x A100 (40GB)    | $32.77     |
| p3.2xlarge   | 1x V100 (16GB)    | $3.06      |
| p3.8xlarge   | 4x V100 (16GB)    | $12.24     |
| g6.xlarge    | 1x L4 (24GB)      | $0.80      |
| g5.xlarge    | 1x A10G (24GB)    | $1.01      |

**優點：**

- 企業級 SLA，保證 99.99% 正常運作時間
- 具備 SOC2、HIPAA 與 FedRAMP 等合規認證
- 橫跨 30 個以上的區域，全球皆可使用
- 與 AWS 機器學習服務深度整合

**限制：**

- 在所有分析的供應商中價格最高
- 不提供消費級 GPU（沒有 RTX 系列）
- 計價結構複雜，頻寬與儲存空間另外計費
- 必須簽 1-3 年的承諾方案才有大幅折扣

### 情境 1：Stable Diffusion LoRA 訓練

為 Stable Diffusion 訓練自訂 LoRA 模型，在 24GB GPU 上通常需要 1-3 小時。

| 供應商  | 計算方式               | 總費用    |
| ------- | ---------------------- | --------- |
| AWS     | 不適用（無此 GPU）     | —         |
| Azure   | 不適用（無此 GPU）     | —         |
| GCP     | 不適用（無此 GPU）     | —         |

選擇 GPU 租用供應商，需要把您的具體需求和各供應商的能力對照比較。以下框架可以協助您做決定。

### 以下情況選擇 AWS：

- 貴組織已有 AWS 基礎架構與相關專業
- 合規要求必須具備 SOC2、HIPAA 或 FedRAMP 認證
- 工作負載需要保證 99.99% 的正常運作時間
- 穩定度與支援比預算更重要
- 需要與 SageMaker 或其他 AWS AI 服務整合

### 以下情況選擇 Azure：

- 您以 Microsoft 的 AI 技術堆疊（OpenAI、Azure ML）為開發基礎
- 混合雲需求涉及與自建機房整合
- 貴組織以 Microsoft 企業工具為標準
- 需要使用 Azure 獨家的特定 GPU 配置

### 以下情況選擇 GCP：

- 您的特定工作負載需要使用 TPU
- 您深度投入 Google 的資料生態系（BigQuery、Vertex AI）
- TensorFlow 是您的主要框架
- 您想要超大規模雲端業者中最具競爭力的 Spot 價格

### 以下情況選擇 RunPod：

- 您想要市集平台的價格，加上代管服務的穩定度
- 需要使用消費級 GPU（RTX 4090、3090）
- 預設範本能加快您的工作流程
- 您希望在成本與支援之間取得平衡

### 以下情況選擇 Vast.ai：

- 絕對的最低成本是您的首要目標
- 您的工作負載可以容忍偶爾中斷
- 您能自行評估個別出租者的穩定度
- 地理分布或特定硬體配置對您很重要

### 以下情況選擇 GPUFlow：

- 您需要的是透過相容 OpenAI 的 API 使用開放 AI 模型，而不是一台機器
- 您不想自己設定驅動程式、容器或推論伺服器
- 您想為預訂的時數按秒付費，未使用的時間會退還
- 您不需要訓練模型或執行自己的程式碼

## 常見問題

### 租用 GPU 做 AI 訓練，最便宜的方式是什麼？

點對點市集平台的 GPU 租金最低。2026 年 2 月，Vast.ai 上的 RTX 4090 每小時 $0.29 起，而在代管平台上取得同等運算能力要 $1.50 以上，在企業級雲端則要 $3 以上。代價是必須接受不固定的可用性，穩定度也只能參考社群評價，而沒有保證的 SLA。

### 租用一張 NVIDIA A100 GPU 要多少錢？

A100 的租金因供應商而有極大差異。企業級雲端的單張 GPU 每小時收費 $3-4，不過通常會把多張 GPU 綁在較大的執行個體中計價。RunPod 的 A100 每小時 $1.39-1.49。Vast.ai 等市集平台上，個人出租者提供的 A100 每小時 $0.84 起。

### 租 GPU 比買 GPU 便宜嗎？

如果只是間歇性使用，租用的成本效益更好。一張 RTX 4090 的售價為 $1,600-2,000。以市集平台每小時 $0.50-0.80 的租金計算，損益兩平點落在 2,000-4,000 小時之間，相當於全天候不間斷運作 83-167 天。大多數訓練模型或定期執行推論工作的使用者，都不會用到這個門檻。

如果連續好幾個月每天都要使用 8 小時以上，或是基於資安或延遲考量需要專用硬體，購買才比較合理。

### 雲端 GPU 供應商和 GPU 市集平台有什麼不同？

雲端 GPU 供應商（AWS、Azure、GCP）營運企業級資料中心，提供標準化的硬體配置、有保證的可用性 SLA 與合規認證。價格反映的是基礎架構投資、支援成本與穩定度保證。

Vast.ai 等 GPU 市集平台，則是匯集個人硬體擁有者的運算資源，包括遊戲電腦、退役的挖礦機與私人資料中心。點對點模式省去了集中式基礎架構的成本，讓價格能降低 60-80%。代價包括可用性不固定、不同出租者之間效能不一致，以及支援仰賴社群而非有保證的服務。

### 做機器學習訓練該租哪一種 GPU？

GPU 的選擇取決於模型大小與訓練需求：

- **LoRA 微調、Stable Diffusion、小型模型：** RTX 4090 (24GB) 性價比最佳
- **7B-13B 參數的 LLM：** A100（40GB 或 80GB）才有足夠的記憶體容量
- **70B 以上參數的模型：** 需要 H100 (80GB) 或多 GPU 配置
- **推論工作負載：** L4 或 T4 GPU 能以合理成本提供推論服務

對大多數剛踏入 AI 開發的使用者來說，先以每小時 $0.50-0.80 租用 RTX 4090，就能用極低的成本進行實驗，等需求成長再升級到資料中心級 GPU。

### GPU 租用有隱藏費用嗎？

有幾個因素會讓 GPU 租用成本超出標示的每小時費率：

- **儲存空間：** 許多供應商對超出基本預設的磁碟空間另外收費
- **頻寬：** 企業級雲端會收取資料傳輸費，通常每 GB $0.05-0.15
- **閒置時間：** GPU 一旦佈建就會持續計費，記得終止執行個體
- **設定時間：** 部署範本、設定環境與傳輸資料，都會增加非運算時間
- **平台手續費：** 市集平台會從出租者的租金收入中抽取 10-30%，這會反映在價格上

市集平台的計價通常較透明，附加費用也較少。使用企業級雲端時，則需要仔細留意完整的費用結構。
